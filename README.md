**A complete container image supply chain security platform.
Every image is automatically signed with Cosign keyless signing via Sigstore,
has an SBOM generated by Syft, and is verified against Rekor's transparency log.
Kyverno and OPA Gatekeeper enforce that no unsigned image can run in the EKS cluster.**

## How It Works

**Cosign keyless signing**
No private key is stored anywhere. GitHub Actions uses its OIDC
token to authenticate with Sigstore's Fulcio CA, which issues a
short-lived certificate bound to the workflow identity. The signature
and certificate are recorded in Rekor's public transparency log.
Anyone can verify the image was built by this exact GitHub Actions
workflow.

**Syft SBOM**
Syft scans the built image and generates a full Software Bill of
Materials in SPDX JSON format, listing every package and dependency
inside the image. The SBOM is attached to the image in the registry
as an OCI artifact and uploaded as a pipeline artifact.

**Kyverno policy enforcement**
Kyverno runs as an admission webhook. When a pod is submitted to
the cluster, Kyverno intercepts it and verifies the image signature
against Rekor before allowing it to run. Unsigned images are blocked
at admission — they never reach the scheduler.

**OPA Gatekeeper**
A second enforcement layer using Rego policies. Gatekeeper blocks
images from unapproved registries and images using the `:latest` tag,
ensuring every running image is traceable to a specific build.

**IRSA for GitHub Actions**
GitHub Actions authenticates to AWS via OIDC — no static AWS
credentials stored anywhere. Terraform provisions the OIDC provider
and IAM role with least-privilege ECR permissions scoped to this
repository only.

## Project Structure

```
container-supply-chain-security/
│
├── .github/workflows/
│   └── supply-chain.yml          # Build · Sign · SBOM · Push · Verify
```

## Deployment

### Phase 1 — EKS Fargate Cluster

```bash
eksctl create cluster \
  --name supply-chain-cluster \
  --region us-east-1 \
  --fargate

for ns in kyverno gatekeeper-system kyverno-policy-reporter demo-app; do
  eksctl create fargateprofile \
    --cluster supply-chain-cluster \
    --region us-east-1 \
    --name fp-${ns} \
    --namespace ${ns}
done

aws eks update-kubeconfig \
  --region us-east-1 \
  --name supply-chain-cluster
```

### Phase 2 — Infrastructure via Terraform

```bash
cd terraform
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply --auto-approve
terraform output
```

Add the outputs as GitHub repository secrets:

| Secret | Value |
|--------|-------|
| `AWS_ROLE_ARN` | From `terraform output github_actions_role_arn` |
| `ECR_REGISTRY` | From `terraform output ecr_registry` |
| `ECR_REPOSITORY` | `devops-demo-app` |

### Phase 3 — Deploy Kyverno

```bash
helm repo add kyverno https://kyverno.github.io/kyverno/
helm repo update

helm install kyverno kyverno/kyverno \
  --namespace kyverno \
  --create-namespace \
  --version 3.1.4 \
  --set admissionController.replicas=3 \
  --set backgroundController.resources.requests.memory=512Mi \
  --set backgroundController.resources.requests.cpu=250m \
  --set admissionController.container.resources.requests.memory=512Mi \
  --set admissionController.container.resources.requests.cpu=250m

kubectl get pods -n kyverno --watch
```

### Phase 4 — Deploy OPA Gatekeeper

```bash
helm repo add gatekeeper \
  https://open-policy-agent.github.io/gatekeeper/charts
helm repo update

helm install gatekeeper gatekeeper/gatekeeper \
  --namespace gatekeeper-system \
  --create-namespace \
  --version 3.14.0 \
  --set resources.requests.memory=512Mi \
  --set resources.requests.cpu=250m \
  --set postInstall.labelNamespace.enabled=false

kubectl get pods -n gatekeeper-system --watch
```

### Phase 5 — Deploy Kyverno Policy Reporter

```bash
helm repo add policy-reporter \
  https://kyverno.github.io/policy-reporter
helm repo update

helm install policy-reporter policy-reporter/policy-reporter \
  --namespace kyverno-policy-reporter \
  --create-namespace \
  --version 2.24.0 \
  --set ui.enabled=true \
  --set kyvernoPlugin.enabled=true \
  --set resources.requests.memory=512Mi \
  --set resources.requests.cpu=250m

kubectl get pods -n kyverno-policy-reporter --watch
```

### Phase 6 — Apply Policies

```bash
# Kyverno policies
kubectl apply -f policies/kyverno/
kubectl get clusterpolicy

# Gatekeeper constraint templates (apply first, wait for CRDs)
kubectl apply -f policies/gatekeeper/templates/
kubectl get constrainttemplate

# Gatekeeper constraints
kubectl apply -f policies/gatekeeper/constraints/
kubectl get constraints
```

### Phase 7 — Trigger the Pipeline

```bash
git add .
git commit -m "feat: container image supply chain security"
git branch -M main
git push -u origin main
```

Watch GitHub Actions — the pipeline builds, signs, generates the SBOM,
pushes to ECR and ghcr.io, then verifies the signature automatically.

### Phase 8 — Deploy Signed App

After the pipeline completes, update `apps/demo-app/deployment.yaml`
with your actual ECR image digest, then:

```bash
kubectl apply -f apps/demo-app/deployment.yaml
kubectl get pods -n demo-app --watch
```

## Verification

### Verify image signature

```bash
cosign verify \
  --certificate-identity-regexp="https://github.com/Eaglewings966/cosign-image-supply-chain" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  YOUR_ECR_REGISTRY/devops-demo-app:latest

# Or use the helper script
bash scripts/verify-image.sh YOUR_ECR_REGISTRY/devops-demo-app@sha256:<digest>
```

### Inspect SBOM

```bash
bash scripts/inspect-sbom.sh YOUR_ECR_REGISTRY/devops-demo-app@sha256:<digest>
```

### Open Policy Reporter dashboard

```bash
kubectl port-forward svc/policy-reporter-ui \
  -n kyverno-policy-reporter 8082:8080 &
# Open http://localhost:8082
```

## Production Considerations

| Gap | Current State | Production Solution |
|-----|--------------|---------------------|
| SBOM attestation | Attached as OCI artifact | Sign the SBOM with cosign attest |
| Rekor private instance | Public Rekor | Deploy private Rekor for air-gapped environments |
| Policy scope | demo-app namespace only | Apply policies cluster-wide |
| Gatekeeper audit | Not enabled | Enable audit mode to scan existing workloads |
| Image digest pinning | Tag-based | Pin all images to SHA256 digest |
| Multi-registry | ECR + ghcr.io | Add Artifact Registry, ACR as needed |
| Vulnerability scanning | ECR scan on push | Integrate Grype or Trivy in pipeline |

## Destroy Everything

```bash
# 1 — Remove application resources
kubectl delete -f apps/demo-app/ --ignore-not-found=true

# 2 — Remove policies
kubectl delete -f policies/kyverno/ --ignore-not-found=true
kubectl delete -f policies/gatekeeper/constraints/ --ignore-not-found=true
kubectl delete -f policies/gatekeeper/templates/ --ignore-not-found=true

# 3 — Uninstall Helm releases
helm uninstall policy-reporter -n kyverno-policy-reporter
helm uninstall gatekeeper -n gatekeeper-system
helm uninstall kyverno -n kyverno

# 4 — Delete namespaces
kubectl delete namespace kyverno gatekeeper-system \
  kyverno-policy-reporter demo-app --ignore-not-found=true

# 5 — Delete ECR images
aws ecr batch-delete-image \
  --repository-name devops-demo-app \
  --image-ids "$(aws ecr list-images \
    --repository-name devops-demo-app \
    --query 'imageIds[*]' \
    --output json)" \
  --region us-east-1

# 6 — Destroy Terraform resources
cd terraform && terraform destroy --auto-approve

# 7 — Delete EKS cluster
eksctl delete cluster \
  --name supply-chain-cluster \
  --region us-east-1
```

> Verify ECR repository, IAM role, and OIDC provider are removed in the AWS console.
